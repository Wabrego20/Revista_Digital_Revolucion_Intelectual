# Revista Digital de la Revolución Intelectual

Proyecto web educativo desarrollado con:
- HTML5
- CSS3
- JavaScript
- Enlaces internos de ida y vuelta
- Webgrafía con fuentes históricas y documentación técnica
- Diseño responsive para computadora y celular

## Cómo usarlo
1. Abre `index.html` en tu navegador.
2. Edita los datos de la hoja de presentación directamente en `index.html`.
3. Si deseas publicarlo, sube los tres archivos (`index.html`, `style.css`, `script.js`) a GitHub Pages, Netlify, Vercel o un hosting tradicional.

## Archivos
- `index.html`: contenido y estructura.
- `style.css`: diseño, colores y responsive.
- `script.js`: menú móvil y animaciones.
